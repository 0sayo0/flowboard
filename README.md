# FlowBoard

Collaborative project management platform built as a modern full-stack MERN application.

## Status

🚧 In active development.

## Architecture

FlowBoard is organized as a lightweight npm workspaces monorepo with two independent applications:

- `apps/web` — React SPA
- `apps/api` — Express REST API

Frontend and backend are developed, built, tested, and deployed independently while sharing a single repository and development workflow.
